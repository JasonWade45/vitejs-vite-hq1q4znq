# 📈 المرشد الذكي للبورصة — Smart Stock Mentor

منصة عربية للبورصة المصرية والأسواق العالمية: تحسب **صافي مرتبك بعد الأقساط**، تختارلك **أفضل أسهم اليوم** مع نطاق الشراء ووقف الخسارة والمستهدف، وتتابع محفظتك تلقائياً — لكل مستخدم حساب مستقل.

An Arabic-first, local-first EGX & global markets platform: computes your net monthly surplus after installments, picks today's top stocks with entry/target/stop zones, and auto-refreshes every 5–10 seconds. Every account is fully isolated and stored on-device.

> **لا توجد حسابات جاهزة أو بيانات مُعبّأة مسبقاً.** أول مرة تفتح المنصة، تنشئ حسابك الخاص، ثم تُدخل **مرتبك ومصاريفك وأقساطك** إجبارياً قبل ما تدخل لأي شاشة — وبعدها تنطلق الجولة الإرشادية المضيئة تلقائياً.
>
> **No demo accounts or pre-filled data ship with the app.** First run: create your own account → forced salary/installments onboarding → guided tour.

## ✨ المزايا الأساسية | Key Features

1. **🔐 شاشة تسجيل دخول وإنشاء حساب جديد** — بالاسم والرقم السري (4–6 أرقام). كل حساب يحتفظ ببياناته ومعاملاته ومرتبه وأقساطه وقائمة متابعته ودردشته بشكل **مستقل تماماً** على نفس الجهاز. الأرقام السرية تُخزّن كهاش مُملّح (salted hash) ولا تُرسل لأي خادم.
2. **🧭 إعداد إجباري لأول مرة (Salary Onboarding)** — بعد التسجيل مباشرةً، لازم تُدخل: المرتب الشهري، المصاريف المعيشية، قائمة الأقساط (أو تقر إن مفيش أقساط)، ونسبة احتياطي الطوارئ — مع ملخص حي لـ«الصافي المتاح للاستثمار»، والمنصة ما بتسمحش بالدخول لو الالتزامات أكبر من المرتب.
3. **👋 ترحيب شخصي في كل مكان** — تحية باسمك في الشريط العلوي ولوحة البداية وجميع التقارير، مع **جولة إرشادية مضيئة (Spotlight Tour)** تتنقل تلقائياً بين الأقسام مع زر إغلاق **X** يحفظ اختيارك فلا تعود تظهر، وتشتغل تلقائياً بعد الـ onboarding.
4. **📱 واجهة للموبايل والكمبيوتر** — شريط تنقل سفلي ثابت للهاتف (5 أقسام + ورقة «المزيد»)، وتنقل مرقّم للويب، أهداف لمس كبيرة (44px+)، ودعم Safe-area وRTL كامل.
5. **📊 مخطط مرتب الشهر والأقساط** — دائرة بيانية (Donut) وشريط مكدس يوضحان: المعيشة ← الأقساط ← احتياطي الطوارئ ← **الصافي المتاح للاستثمار**، مع **ترشيحات الشراء الفوري** (أقوى أسهم مصرية مرجحة) و**تحديث تلقائي كل 5–10 ثوانٍ** (5s / 7s / 10s).
6. **📭 سجل مصداقية نظيف** — سجل الإشارات يبدأ فارغاً تماماً ويُملأ فقط بالإشارات الحقيقية الصادرة مع تتبع النتيجة بعد +5/+10/+20 جلسة. لا توجد إشارات وهمية.

## 🔌 /api/quotes (Vercel Serverless)

على الإنتاج، المتصفح لا يتصل بـ Yahoo مباشرة (CORS) ولا بأي بروكسي خارجي — بيتصل بـ **`/api/quotes?symbols=…`** وهو *serverless function* داخل نفس النشر على Vercel (ملف `api/quotes.js`): يعمل كـ proxy داخلي يُرجع أسعار spark المجمّعة من Yahoo (مع fallback لـ v8 chart لكل رمز)، بـ timeout 7 ثوانٍ، وكاش مشترك 15 ثانية، وقائمة رموز محددة بحد أقصى 30 رمزاً. **لو الـ function فشلت**، الواجهة تسقط تلقائياً على بروكسيات CORS الخارجية، ولو فشلت هي كمان تظهر «أسعار مرجعية» بصراحة.

Locally (`npm run dev` / `vite preview`) فيه ما فيش `/api` — الواجهة تستخدم البروكسيات الخارجية أو الوضع المرجعي.

## 🚀 التشغيل | Getting Started

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # إنتاج محسّن في dist/
npm run preview  # معاينة الإنتاج
```

خطوات أول تشغيل للمستخدم الجديد:
1. افتح تبويب **«حساب جديد»** → الاسم + رقم سري (4–6 أرقام).
2. هتظهر شاشة **«راتبك وأقساطك أول بأول»**: المرتب، المصاريف، الأقساط (أو علّم «لا توجد أقساط عندي»)، نسبة احتياطي الطوارئ.
3. احفظ → هتدخل المنصة والجولة الإرشادية هتبدأ تلقائياً.

## 🗂 بنية التخزين المحلي | Local Storage Layout

كل مفتاح تحت بادئة `mahmoud_stock_mentor_*` (الاسم التاريخي، لا يؤثر على الوظائف):

- `..._users_v3` — جميع الحسابات على هذا الجهاز (بيانات كل مستخدم + هاش رقمه السري)
- `..._session_v1` — الجلسة الحالية
- `..._symbols_v3` / `..._ledger_v3` — بيانات السوق وسجل الإشارات (يبدأ فارغاً)
- `..._chat_v3_<userId>` — سجل محادثة كل مستخدم على حدة
- `..._theme_v3` / `..._hide_tour_v3` — التفضيلات
- `smart_stock_mentor_storage_version` — إصدار هجرة التخزين (v5: يمحو أي حسابات تجريبية قديمة من الأجهزة اللي كانت مثبت عليها نسخة سابقة)

**النسخ الاحتياطي:** من «نشر أونلاين + تطبيق للموبايل» يمكن تحميل/استيراد نسخة JSON — لحسابك الحالي فقط.
